# For New
1. Git-installation
```
git init
```
2.Add files and folder to git for tracking 
```
gitadd .
```
Note: . is for all the files and foler , in place of , we can add file name.
3.After completing :save all codes as some versions
```
git commit -m"[your commit message]"
```
4.OPtional step: chaning main branch 
Note: default branch is always "master"
```
git branch-M "[your main branch name]"
```
5. Add remote repo link or respository url 
``` 
git remote add origin"[your msg ]"
```
6. Push the recent commitedd code to remote git 
```
git push-u `origin` "[msg]"
```
Later ( if one push is already done using -u upstream)
```
git push
```
7.To previews the status of the current git
```
git status
```
8. To check the linked remote url
```
git remote-v
```
